# Contributing to PulsoTerra

Use a separate branch and explain the behavior changed. Run the Node suite and check affected keyboard journeys. For image changes, preserve the NASA color/reference meaning, source hashes, and missing-data behavior. For sound changes, document the parameter mapping, sample provenance, and license rather than relying on a description of the intended emotion.

Keep English and Spanish labels and narratives equivalent. Do not translate the name PulsoTerra. Add a text alternative to new audio guidance. Avoid autoplay, focus removal, automatic application of draft selector choices, and continuous live-region narration. Test the offline build when assets or script inclusion change.

Do not commit credentials, private conversations, computer screenshots, personal paths, or local research caches. Keep third-party source notices and required attribution. Do not apply a new repository-wide license to third-party assets. Submit a concise change description and the checks actually performed; separate automated/browser checks from real screen-reader or listening evaluation.
